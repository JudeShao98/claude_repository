# BA II Plus · CFA 金融计算器

一个纯前端的 **TI BA II Plus** 金融计算器网页应用，面向 CFA 考试常用功能。原生 HTML / CSS / JavaScript 实现，**无需安装、无需联网、数据不离开本机**，手机和电脑浏览器都能直接使用。

## 功能

分三个标签页：

### 1. TVM 货币时间价值
求解 `N`、`I/Y`（年利率 %）、`PV`、`PMT`、`FV` 五个变量。填入已知的 4 个，点对应行的 **CPT** 即可算出第 5 个。

- 支持 `P/Y`（每年付款次数）与 `C/Y`（每年复利次数），可处理月供、半年付息债券等
- 支持期末 `END` / 期初 `BGN`（年金 vs 先付年金）
- 现金流符号遵循 BA II Plus 约定：**流入为正、流出为负**

### 2. 现金流 NPV / IRR
- 输入 `CF0` 及各期现金流，`F` 表示该现金流连续出现的次数
- `CPT NPV`：按每期折现率 `I`(%) 计算净现值
- `CPT IRR`：计算内部收益率（每期 %）

### 3. 标准计算
带正负号、百分比、退格的四则运算键盘。

> 数学引擎已对照 CFA 教材标准例题逐项验证（一次性求值、年金、月供、债券定价、NPV、IRR 等），并在无头浏览器中做过端到端冒烟测试。

## 使用方式

### 在线使用（手机推荐）
部署到 GitHub Pages 后，直接在手机浏览器打开站点链接即可，可“添加到主屏幕”当 App 用。

### 本地使用
直接双击 `index.html`，或起一个静态服务器：

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 上手示例

| 题目 | 输入 | 操作 | 结果 |
| --- | --- | --- | --- |
| 1000 元、8%、10 年的终值 | N=10, I/Y=8, PV=−1000 | CPT FV | 2158.93 |
| 30 年月供（房贷 20 万，6%/年） | N=360, I/Y=6, PV=200000, P/Y=C/Y=12 | CPT PMT | −1199.10 |
| 现金流 −1000, 500×3 的 IRR | CF0=−1000, C01=500 F=3 | CPT IRR | 23.38% |

## 文件结构

```
index.html      页面结构与三个标签页
baii.css        样式（深色、移动优先）
baii-core.js    金融数学引擎（TVM / NPV / IRR），可在 Node 中单测
baii-ui.js      界面逻辑与事件处理
```

## 说明
本应用为功能等价的金融计算器，**采用表单+CPT 的求解方式**，而非逐键模拟真实 BA II Plus 的按键序列，更适合手机操作、不易出错。
