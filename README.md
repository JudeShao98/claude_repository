# 计算器 Calculator

一个纯前端的计算器应用，使用原生 HTML / CSS / JavaScript 实现，**无需任何构建工具或依赖**。

## 功能

- 加 (`+`)、减 (`−`)、乘 (`×`)、除 (`÷`) 四则运算
- 百分比 (`%`)、清除 (`AC`)、退格 (`DEL`)
- 连续运算（链式计算），例如 `5 + 3 × 2`
- 除以零错误提示（显示 `Error`）
- 浮点数精度处理（避免 `0.1 + 0.2 = 0.30000000000000004`）
- 千位分隔符显示
- 完整的键盘支持
- 响应式深色界面

## 使用方式

### 方式一：直接打开（最简单）

双击 `index.html`，或在浏览器中打开它即可使用。

### 方式二：本地静态服务器（推荐）

在仓库根目录运行任意一种命令，然后访问 http://localhost:8000

```bash
# Python 3
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

## 键盘快捷键

| 按键              | 功能       |
| ----------------- | ---------- |
| `0`–`9`           | 输入数字   |
| `.`               | 小数点     |
| `+` `-` `*` `/`   | 运算符     |
| `Enter` 或 `=`    | 计算结果   |
| `Backspace`       | 退格 (DEL) |
| `Escape`          | 清除 (AC)  |
| `%`               | 百分比     |

## 文件结构

```
index.html      页面结构与按键布局
style.css       样式与深色主题
calculator.js   计算逻辑与键盘 / 点击事件处理
```
